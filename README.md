# mototrack

Gratis og kostnadsfri løsning for å spore turer og dele resultater uten betalt backend.

## Hvordan det fungerer
- Appen kan kjøres som en enkel statisk nettside.
- Resultater lagres lokalt i nettleseren som standard.
- Du kan dele et resultat med andre via en lenke som inneholder dataene, uten serverkostnader.
- For gratis publisering kan prosjektet hostes på GitHub Pages.

## Publiser gratis på GitHub Pages
1. Push prosjektet til GitHub.
2. Gå til repository settings → Pages.
3. Velg "GitHub Actions" som kilde.
4. Workflowen i .github/workflows/deploy-pages.yml vil publisere siden automatisk.
